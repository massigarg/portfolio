# Personal Portfolio

A personal portfolio website showcasing projects, blog posts, and professional background.

## About

This static website features:
- Personal introduction and professional background
- Data science and software engineering projects
- Technical blog posts on topics like TDD, blockchain, and NLP
- Reading list and book recommendations
- Skills and experience timeline

## GitHub Pages Deployment

This site is designed to be deployed on GitHub Pages. To deploy:

1. Push this repository to GitHub
2. Go to repository Settings → Pages
3. Select "Deploy from a branch" 
4. Choose "main" branch and "/ (root)" folder
5. Your site will be available at `https://yourusername.github.io/repository-name`

## Technology Stack

- **Frontend**: HTML, CSS, Bootstrap 5
- **Fonts**: Google Fonts (Nunito)
- **Styling**: Custom CSS with responsive design
- **Deployment**: GitHub Pages (static hosting)
